# 天气助手 Agent 产品设计文档

## 1. 产品概述

天气助手 Agent 是一个基于大语言模型和实时天气工具的对话式助手。用户使用自然语言提问，模型识别查询意图并调用天气服务获取数据，再将结果整理成易懂的中文回答。

第一阶段以命令行 MVP 为主，验证“自然语言理解—工具调用—结果生成”的完整闭环。第二阶段增加大模型自然语言理解和 HTTP API，为前端聊天界面提供稳定入口。

## 2. 产品目标

- 让用户通过自然语言快速查询实时天气。
- 验证大模型调用外部工具完成任务的基本模式。
- 保持天气数据来源与模型逻辑解耦，便于后续替换服务和扩展能力。

## 3. 目标用户

- 希望快速查询城市天气的普通用户。
- 学习大模型 Agent、Function Calling 和工具编排的开发者。

## 4. 核心使用场景

用户输入：

> 北京今天会下雨吗？

系统流程：

1. 模型识别这是实时天气查询，并提取地点、日期等参数。
2. Agent 调用 `get_weather` 工具，请求天气数据服务（首选 wttr.in）。
3. 工具返回标准化天气数据。
4. 模型根据数据生成简洁、自然的中文回答。

## 5. 主要功能

### 5.1 自然语言天气查询

- 查询指定城市的当前天气或当天预报。
- 支持温度、天气状况、湿度、风速、降雨概率等信息。
- 默认使用摄氏温度，并在回答中明确地点和日期。

### 5.2 工具调用

- 提供 `get_weather` 天气查询工具。
- 模型在涉及实时天气时必须调用工具，不直接猜测数据。
- 工具返回统一格式，屏蔽底层天气服务的响应差异。

### 5.3 澄清与错误处理

- 用户未提供地点时，主动询问城市或地区。
- 天气服务超时、不可用或返回异常时，向用户说明暂时无法查询。
- 对暂不支持的需求（如精确定位、长期气候分析）给出清晰提示。

### 5.4 交互入口

- MVP：命令行交互。
- 当前迭代：提供 `POST /api/chat` HTTP API，接收当前消息和有限对话历史。
- 后续：接入 Web 或其他聊天界面。

### 5.5 多轮上下文

- 客户端在请求中携带本次对话历史。
- 支持用户先提出天气问题，系统追问地点，用户再补充城市。
- 当前不保存服务端会话，不引入账号、数据库或长期记忆。

## 6. 数据与技术方向

- 大模型：负责意图识别、参数提取、工具选择和最终回答。
- 天气服务：首选 wttr.in，后续可替换为 Open-Meteo 等服务。
- 天气适配层：将外部响应转换为统一的内部数据结构。
- 可选增强：短时缓存、请求超时、日志和基础监控。
- 当前展示版本已增加城市别名解析、时区标注、短时缓存、未来 3～7 天预报和浏览器聊天界面。
- 当前可靠性迭代已增加健康检查、请求耗时日志和输入边界保护。

## 7. MVP 范围与边界

### 本期包含

- 一个天气查询工具。
- 一个城市、当天/当前天气的查询闭环。
- 中文文本回答。
- 基础的网络异常和参数缺失处理。
- OpenAI 兼容大模型的自然语言意图提取和回答生成。
- 支持有限对话历史的 HTTP API。

### 本期不包含

- 用户账号、历史记录和个性化设置。
- GPS 或 IP 自动定位。
- 多轮复杂行程规划和主动推送天气预警。
- 面向生产环境的高可用和复杂权限体系。

## 8. 验收标准

- 输入“上海今天会下雨吗？”时，系统能够调用天气工具并返回基于实时数据的中文回答。
- 未提供地点时，系统会先请求补充地点。
- 天气服务失败时，系统不会编造天气信息，并返回友好提示。
- 天气解析、工具调用和异常处理具备自动化测试。
- HTTP API 能接收消息和历史记录，并返回统一状态及中文回答。
- 大模型或天气服务失败时不会生成无数据依据的天气结论。

## 9. 后续迭代方向

- 支持未来 3～7 天预报和更多天气指标。
- 增加地点解析、时区处理和用户当前位置。
- 引入缓存与备用天气数据源。
- 增加 Web UI、语音交互和天气预警订阅。

## 10. 当前迭代：可靠性与可观测性

第二阶段完成后，当前迭代优先补齐运行边界，而不扩展复杂业务能力：

- 增加 `GET /health` 健康检查接口。
- 记录 API、天气服务和大模型调用耗时，以及 provider、状态和错误类型。
- 无模型模式下明确拒绝明天、后天和多日预报，避免将日期误识别为城市。
- 限制单条消息最多 2000 个字符，历史最多 20 条，每条历史消息最多 2000 个字符。
- 为上述边界和可观测性行为增加自动化测试。

本轮实际实现顺序调整为：短时缓存 → 地点解析与时区 → 未来 3～7 天预报 → Web UI；不引入 Open-Meteo 备用数据源。
